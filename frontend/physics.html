KTC model IEDF/IADF Simulator — モデル解説

← シミュレーターへ戻る

1. 全体像

本シミュレーターは、容量結合RFプラズマ（CCP）のシースを通過するイオンの エネルギー分布（IEDF）と角度分布（IADF/IAEDF）を、 以下の3段階で計算する。論文ベンチマーク（Kawamura 1999, Wild&Koidl 1991, Qin&Wendt 2010, Seong 2022）で検証済みのコンポーネント構成である。

  1. グローバル回路モデル（KCL）: 駆動波形からプラズマ電位 \(V_p(t)\) とシース電圧を自己無撞着に決定
  2. 規定電場シースモデル: シース内の瞬時電場プロファイルを解析形で規定（2Dでは Laplace 3基底 + 空間電荷補正）
  3. TPMC（Test Particle Monte Carlo）: シース端から入射したイオンを電場と中性粒子衝突のもとで追跡し、電極到達時の \((E, \theta)\) を集計

2. プラズマの基礎量

入力は電子温度 \(T_e\)、シース端密度 \(n_s\)、イオン質量 \(M\)、RF周波数 \(f\)。ここから

$$u_B = \sqrt{\frac{e T_e}{M}}, \qquad J_i = e\, n_s u_B, \qquad J_{e,\mathrm{sat}} = e\, n_s \sqrt{\frac{e T_e}{2\pi m_e}}, \qquad \lambda_D = \sqrt{\frac{\varepsilon_0 T_e}{e\, n_s}}$$

\(u_B\) はBohm速度で、TPMCの初期条件としてイオンはシース端で \(v_x = u_B\)（+イオン温度による熱広がり）を持つ。 これは無衝突プレシースの電位降下 \(\simeq T_e/2\) をすでに含んだ入射条件である。 静的な浮遊電位差の目安は \(\Delta V_f = T_e \ln(J_{e,\mathrm{sat}}/J_i)\)（Ar, 3 eVで約14 V）。

3. 自己無撞着プラズマ電位（KCL回路モデル）

プラズマバルクを浮遊する等電位節点とみなし、各電極シースを 「伝導電流 + シース容量の変位電流」の並列素子としてキルヒホッフ電流則（KCL）を課す。 1D（駆動電極 p / 接地電極 g、面積比 \(A_p/A_g\)）では

$$A_p\!\left[J_{\mathrm{cond}}(V_{sp}) + C_s(V_{sp})\frac{d(V_p - V_e)}{dt}\right] + A_g\!\left[J_{\mathrm{cond}}(V_{sg}) + C_s(V_{sg})\frac{dV_p}{dt}\right] = 0$$

ここで各シースの伝導電流はイオン飽和流と電子のBoltzmann応答の和:

$$J_{\mathrm{cond}}(V_s) = J_i - J_{e,\mathrm{sat}}\, e^{-V_s / T_e}$$

シース容量は瞬時Child-Langmuir幅 \(s(V_s)\) の平行平板近似:

$$C_s = \frac{\varepsilon_0}{s(V_s)}, \qquad s(V_s) = \sqrt{\frac{4}{9}\,\varepsilon_0 \sqrt{\frac{2e}{M}}\;\frac{V_s^{3/2}}{J_i}} \quad (\ge \lambda_D)$$

この常微分方程式をRK4で周期定常（周期端点の \(V_p\) 差が許容値以下）まで積分する。 2Dではウェハ・エッジリング・接地の3シースに拡張し、 リングには独立な駆動波形（CSV/正弦波/ウェハ波形スケール）を与えられる。 KCL残差は数値検証セルで \(10^{-14}\) オーダーであることを確認している。

波形はCSVで任意形状を与えられる。tailored waveform（多高調波合成）による 単色IEDF・エネルギー制御性は Qin&Wendt 2010 ベンチマークで確認済み。

4. シース電場モデル（1D）

4.1 Child型電位プロファイル

シース内の電位を \(\phi \propto x^{\alpha}\)（既定 \(\alpha = 4/3\): 無衝突Child則）と規定し、電場は

$$E(x, t) = \alpha\,\frac{V_s(t)}{s}\,\xi^{\alpha - 1}, \qquad \xi = \frac{x - x_{\mathrm{front}}}{s_e}\in[0,1]$$

二峰性IEDFのピーク間隔がBenoit-Cattin式と5%以内で一致することをKawamura 1999ベンチマークで確認している。

4.2 電子フロント運動シース（既定）

シース幅はRF位相とともに振動する。既定の moving_front モデルでは、 瞬時シース電圧に応じた電子フロント位置を運動学的Child則で置く:

$$s_e(t) = s_{\max}\left(\frac{V_{sp}(t)}{V_{sp,\max}}\right)^{p}, \qquad p = 3/4$$

フロントよりプラズマ側（\(x < s_{\max} - s_e\)）は電場ゼロの準中性領域とする。 イオン通過周期数が解析式 \(\tau_{\mathrm{ion}} = 3\bar{s}\sqrt{M / 2e\bar{V}_s}\) と2–3%で一致することをWild&Koidl 1991ベンチマーク拡張で確認している。

5. TPMC（1D3V）

各テスト粒子はRF位相を一様乱数で与えられ、シース端 \(x=0\) からBohm速度で入射し、運動方程式

$$M\frac{dv_x}{dt} = e\,E(x, t)$$

を時間刻み \(\Delta t = T_{RF}/N_{\mathrm{steps}}\) で積分する。1ステップの衝突確率は

$$P_{\mathrm{coll}} = 1 - \exp\left[-n_g\, \sigma_{\mathrm{tot}}(E_{cm})\, v\, \Delta t\right], \qquad n_g = \frac{p}{k_B T_g}$$

衝突種別はエネルギー依存断面積の比で決める:

  • 電荷交換（CX, backscat）: イオン速度を中性粒子の熱速度で置換 → 低エネルギーピーク群を生む
  • 等方弾性散乱（isotropic）: 重心系で等方散乱 → 角度広がりを生む

断面積は既定でLXCat Phelpsデータベースの評価済みAr⁺/Ar断面積 （backscat=CX相当、isotropic=等方弾性）をlog-log補間して用いる。 電極到達時に \(E = \tfrac{1}{2}Mv^2/e\) と符号付き入射角 \(\theta = \mathrm{atan2}(v_y, |v_x|)\) を記録する。

5.1 静磁場（オプション、イオンのみ）

一様な静磁場 \(\mathbf{B}\) を指定すると、運動方程式は

$$M\frac{d\mathbf{v}}{dt} = e\left(\mathbf{E} + \mathbf{v}\times\mathbf{B}\right)$$

となり、Borisプッシャー（半分の電場キック → 磁場回転 → 半分の電場キック） で積分する。磁場回転は厳密な回転行列なので磁場は仕事をせず、エネルギー保存は 機械精度で維持される。座標系は 1D: \(x\)=シース深さ方向・\(y\)=面内横方向・ \(z\)=第3軸、2D: \(x\)=横方向・\(y\)=鉛直・\(z\)=面外。 主な効果はイオンジャイロ運動による入射角のシフト（目安 \(\omega_{ci}\tau_{\mathrm{ion}}\)、 \(\omega_{ci} = eB/M\)）と \(\mathbf{E}\times\mathbf{B}\) ドリフトで、 検証表に \(\omega_{ci}\Delta t\)（< 0.3 を要求）とジャイロ半径/シース幅比が表示される。 電場の与え方（KCL・Child則・Laplace基底）は無磁化電子を仮定したままのため、 電子の磁化がシース構造を変える強磁場領域は適用外（8章参照）。

6. 2Dモデル（ウェハ + エッジリング）

6.1 ジオメトリと境界条件

計算領域は \(x \in [0, L]\) の非周期領域で、左右の壁は鏡像対称境界 （\(\partial\phi/\partial x = 0\)、イオンは鏡面反射）。表面は制御点折れ線 \(y = s(x)\) で、セグメントごとに境界材質を割り当てる:

  • ウェハ: Dirichlet境界 \(\phi = V_w(t)\)（KCL解）
  • エッジリング: Dirichlet境界 \(\phi = V_r(t)\)（KCL解）
  • 絶縁: 非帯電誘電体。電位を固定せず固体内部もLaplace解に含める （\(\varepsilon_r = 1\) 相当、表面帯電なし）。イオンは表面で吸収・記録される

6.2 Laplace 3基底の重ね合わせ

上記境界のもとで2D Laplace方程式を赤黒SORで3回解く。それぞれ プラズマ上端・ウェハ・リングを1、他を0とした基底 \(\psi_p, \psi_w, \psi_r\) で、瞬時電位は

$$\phi(x, y, t) = V_p(t)\,\psi_p + V_w(t)\,\psi_w + V_r(t)\,\psi_r \;(+\,\phi_{sc})$$

3基底の和が active 領域で1になること（partition of unity、誤差 \(\sim 10^{-5}\)）が 重ね合わせの妥当性チェックになる。0.6 mm段差での端傾き1.6–2.3°は Seong 2022 の実測（≤2.5°）と整合する。

6.3 周期平均空間電荷Poisson補正（既定ON）

TPMCで堆積した周期平均イオン密度 \(n_i\) と、全電位に対する位相平均Boltzmann電子 \(n_e = n_s \langle \exp[(\phi - V_p)/T_e] \rangle_{\mathrm{phase}}\) から

$$-\nabla^2 \phi_{sc} = \frac{e\,(n_i - n_e)}{\varepsilon_0}$$

を解き、緩和係数0.35で混合しながら数回反復する（発散抑制のため補正上限と密度クリップあり）。 Poisson補正により端傾きはLaplace版の1.2–1.5倍となり、実測に近づく。

7. 数値検証（各ジョブで自動実行）

  • エネルギー保存: 静的無衝突シースで平均エネルギー利得 = \(eV_s\)（相対誤差 \(10^{-4}\) 以下）
  • 衝突確率: 1ステップ最大衝突確率が推奨上限（既定0.05）以下
  • KCL残差 / partition of unity / 空間電荷収束履歴（2D）
  • Riley較正ブリッジによるΔE見積もり: \(\Delta E = \dfrac{2e\tilde{V}_s}{\sqrt{1 + (\omega \tau_{\mathrm{ion}}/4)^2}}\) （正弦波近似の目安、TPMC比0.95–1.14）

8. 適用限界

  • 規定電場近似のΔE誤差は±16%以内（ハイブリッド1D PICクロスチェック）。完全な自己無撞着PICではない
  • 電子フロント位置は運動学的近似。変位電流と整合する自己無撞着フロントではない
  • \(n_s, T_e\) は入力値（パワーバランスから更新しない）。二次電子・電子慣性なし
  • 静磁場はイオンにのみ作用（Boris法）。電子・シース電場は無磁化のまま計算する ため、電子磁化がシース構造や密度分布を変える領域（マグネトロン級の強磁場や 面平行Bでの \(\mathbf{E}\times\mathbf{B}\) 閉じ込め支配領域）は適用外
  • 弾性散乱は重心系等方（微分断面積の異方性なし）
  • 2D: 絶縁セグメントは非帯電誘電体（\(\varepsilon_r=1\)、表面帯電なし）。 帯電はコーナー集束を増強する方向。逆シース（\(V_s \le 0\)）は適用外
  • 2D: 左右壁は鏡像対称境界。壁近傍の結果は「形状が対称に続く」仮定を含む
